# RimWorld_AI_manager
## Description
AIManager mod adds new dialog window with AI agent where you can write your plan about future development of colony. AI will make strategy: build, destroy or replace buildings and give prioritet tasks to coloniests.

## Features
Mod add new button near to map control buttons. There you can write your plan or open mod settings. (WIP)

## Requierments
* RimWorld version 1.6 
* depends on Harmony
